# UI / VI 改造功能迁移对照（第一阶段）

## 当前状态

本阶段只提供管理员可见的交互样板，不替换线上页面，也不调用 Server Action 或写入业务数据。样板确认后，按共享外壳、图鉴收藏、首页扫描、换谷消息、账号后台的顺序分批接入真实数据。

样板入口：`/admin/design-preview`

## 视觉基准

- 定位：现代、清晰、有收藏质感的个人图鉴 App。
- 品牌：以“谷”字和收藏卡轮廓组合为标志；主色为朱红 `#B93C49`，收藏金 `#B0874F` 只用于点亮和成就。
- 浅色语义：背景 `#F6F7F9`、表面 `#FFFFFF`、正文 `#20242B`、次级文字 `#667085`。
- 字体：系统中文无衬线；正文 14–16px，辅助信息不小于 12px，主要触控区域至少 48px。
- 动效：普通反馈 120–220ms；仅详情卡面保留空间感；减少动态效果时关闭非必要过渡。
- 内容：真实藏品图片优先，不用持续光效、重复渐变或多重边框抢夺注意力。

| 功能       | 原入口 / 状态              | 目标入口 / 表达                                          | 样板验证                               | 推广验收                                              |
| ---------- | -------------------------- | -------------------------------------------------------- | -------------------------------------- | ----------------------------------------------------- |
| 搜索       | 顶部搜索、谷库搜索         | 顶部全局搜索；谷库保留当前结果内搜索                     | 输入即时过滤标题、系列和角色文本       | 旧搜索链接和查询参数继续有效                          |
| 多维筛选   | 分类入口与折叠筛选区       | 手机底部筛选面板；桌面常驻侧栏；已选条件可见可撤销       | 类型筛选、清除、空结果均可交互         | IP → 角色/系列 → SKU 关系、分页不丢失                 |
| 谷库列表   | 多组入口后才出现商品       | 标题、搜索、单行快捷筛选后立即出现首行商品               | 360/390px 首屏可见商品；横竖图不变形   | 加载、错误、空态与真实长标题可用                      |
| 收藏状态   | `owned` 与“已点亮”表达混淆 | 已入柜、已点亮、想要、可换分别表达                       | “已入柜”含 owned/lit；“已点亮”只含 lit | 数量、完成度、库存和履约限制与现有数据一致            |
| 私人实拍   | 与收藏状态混排             | 谷柜平行“实拍”视图                                       | 仅展示 scan 状态样本                   | 未鉴定、私人备注、权限和失败重试保留                  |
| 藏品详情   | 图片、属性和操作层级不统一 | 主图居中；收藏操作优先；评分、实拍、换谷按需展开         | 卡面正反切换；本地状态按钮；折叠分区   | 接回评分、评论、图片、分享、举报和权限                |
| 扫描       | 独立识别流程               | 五栏中突出入口；进入后采用专注布局                       | 本阶段不重做扫描                       | 批量、正反面配对、补拍、候选确认、暂存全部回归        |
| 换谷       | 多处导航且待处理含义混杂   | 发现 / 待处理 / 履约                                     | 本阶段不重做换谷                       | 发布、提案、反提、接受/拒绝、撤回、取消、完成全部保留 |
| 消息与通知 | 红点可能默认常亮           | 红点只绑定真实未读；会话适配软键盘                       | 样板通知不显示假红点                   | 参与者权限、拉黑、举报和输入不中断回归                |
| 全局导航   | 多端表达不完全统一         | 手机：首页 / 谷库 / 扫描 / 换谷 / 我的；桌面独立宽屏导航 | 样板展示统一标志和搜索                 | Android 返回先关临时层；列表位置保留                  |
| 账号与后台 | 功能分散                   | 复用基础颜色、表单、状态和加载规范                       | 管理员可访问样板入口                   | 关注、徽章、账号删除、审核、批量管理和权限不丢失      |

## 第一阶段确认点

1. 品牌标志、浅色与深色语义色是否符合谷布谷定位。
2. 谷库是否能更快看见商品并理解筛选状态。
3. 谷柜是否清楚区分入柜、点亮与私人实拍。
4. 详情是否有“一张实体收藏卡”的主次层级，同时保留完整资料入口。

确认样板后再迁移生产页面；每一批都必须用本表核对原入口、新入口和真实数据行为。
