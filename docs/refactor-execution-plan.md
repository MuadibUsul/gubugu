# 谷布谷全量重构执行计划

状态：已完成（2026-08-22）  
基线：`plan.md`、`strugle.md`、`AGENTS.md`  
原则：SKU 优先、服务端可信、渐进披露、PC 优先、移动端可用、最小依赖、P2 只预留。

## 不可变产品边界

- 保留图鉴、搜索、收藏、识别、评论/评分/照片、轻量换谷、管理后台。
- 保留 P0：收藏数量与可换数量 → 匹配 → 提案快照 → 双方履约 → 评价/信誉 → 通知。
- 保留 P1：资料可见性、关注与轻量 Feed、举报、角色收藏圈、SKU 蹲谷。
- SKU 始终是收藏、匹配、交换、评价和通知的核心关联实体。
- 不实现支付、钱包、托管、仲裁、物流、Push、会员、原生端或自训练视觉模型。

## 目标体验

主路径：`搜索/识别 → SKU → 拥有/想要/可换 → 匹配 → 换谷 → 评价/信誉`。

全局导航只保留：首页（Logo）、搜索、换谷、我的。识别、通知、关注、举报与管理能力放回对应上下文；后台入口仅对管理员渲染，并始终由服务端再次鉴权。

视觉定位为“和纸档案 × 二次元收藏册 × 实体谷子卡片”：米白纸面、墨色、朱红主操作、古金拥有、靛蓝想要、青绿可换；中文主标题优先，原名与 SKU 编号作为次级信息。角色和商品图片承担主要二次元色彩，不使用霓虹、玻璃拟态或大面积渐变。
