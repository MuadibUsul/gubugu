# 发布回归清单

配套 [mobile-first-transformation-plan.md](mobile-first-transformation-plan.md) 的 Phase 0
闸门。每个阶段收尾、以及每次准备上线前跑一遍；勾不满不进下一阶段。

自动化闸门先过，再做人工回归：

```bash
pnpm format:check && pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

涉及数据库时补 `db:migrate` / `db:seed` / `db:verify-rls` / `db:verify-trade` /
`db:verify-lighting`；涉及 Android 时补 `cap:sync` 与 `./gradlew test bundleRelease`。

---

## 一、桌面 Web（Chrome / Edge，1024 / 1280 / 1440）

- [ ] 首页在宽屏用满宽度，不是把手机单列居中放大。
- [ ] **底部五 Tab 不出现在 `>= 1024px`**；顶部/上下文导航可用。
      _当前已知不达标：`nav.app-tabbar` 在 1440px 下仍为 `display: block`，属 Phase 2 待办。_
- [ ] 任意宽度均无横向滚动条。
- [ ] 谷库筛选走侧栏/工具栏形态；筛选后 URL 可分享、可回退。
- [ ] SKU 详情多栏排布，图片、归属、规格、收藏动作在首屏可达。
- [ ] 商品图始终原色——未拥有、愿望、已点亮都不做灰阶。
- [ ] 扫描入口在 PC 不提供伪相机，只给移动端引导。
- [ ] 亮色与暗色主题各走一遍关键页。

## 二、移动 Web（Chrome Android / Safari iOS，360 / 390 / 768）

- [ ] 首屏直接出现搜索与真实内容，无营销 Hero 占位。
- [ ] 底部五 Tab 为 `首页 / 谷库 / 扫描 / 换谷 / 我`，扫描为凸起主操作。
- [ ] 底部 Tab 不遮挡列表末条与表单提交按钮。
- [ ] 键盘弹出时输入框不被顶出视口；收起后布局复原。
- [ ] 安全区（刘海、底部横条）不吞掉内容或操作。
- [ ] 长谷子名在卡片、详情与分享卡都能正确截断或折行，不撑破布局。
- [ ] 轮播、折叠区、弹层在 `prefers-reduced-motion` 下不产生大幅动效。
- [ ] 离线时 `/offline` 可达，恢复后能正常继续。

## 三、Android App（Capacitor 真机）

- [ ] `server.url` 指向正式 HTTPS，无 `cleartext`、无开发地址。
- [ ] 系统返回键逐层退栈，退到首页再按才退出应用。
- [ ] 相机：首次授权、拒绝一次、永久拒绝、设备无相机四种路径都有明确出路。
- [ ] 扫描页退出、切后台、旋转后摄像头资源释放，不残留占用。
- [ ] 深链与外链在 WebView 内/外的落点符合预期。
- [ ] 分享谷子调起系统分享，分享卡图片正常。
- [ ] 断网、弱网、请求超时后恢复，不留白屏。
- [ ] `targetSdkVersion` 保持 36。

---

## 四、跨端共通（每次发布必查）

**身份可见性**——同一 SKU / 主页分别用匿名、本人、关注者、其他登录用户、审核员查看：

- [ ] 公开主页只显示已点亮 SKU。
- [ ] **未鉴定扫描图无法被他人或无鉴权 URL 读取**（直接粘贴图片 URL 到隐身窗口验证）。
- [ ] 换谷库存只来自已点亮拥有。

**数据形态**：

- [ ] 空数据、仅少量数据、数百 SKU 三种规模下版面都成立。
- [ ] 长名称、多角色、多图、无 embedding 的 SKU 不破版、不报错。

**部署相关**（本项目踩过的坑，逐条确认）：

- [ ] 生产镜像内 `sharp` 为 0.33.x —— 0.34+ 的预编译包要求 x86-64-v2，当前 VPS 的
      CPU 不支持，升级会让全站 500。Dockerfile 已有构建期断言。
- [ ] 分享卡 `/goods/*/share` 返回 200 且中文正常（字体未装进系统字体目录时会变豆腐块）。
- [ ] 应用日志无 `EACCES` —— `.next` 需整体可写，否则 ISR 结果无法落盘。
- [ ] 同机 tline 的容器与 `tlines.tech` 不受影响。
