# 谷布谷 · 安卓 App 需求文档（供 AI 完善设计用）

> 一句话：一个二次元周边（谷子）**图鉴 + 私人收藏（谷柜）+ 以物易物（换谷）** 的移动 App。
> 核心差异化：**扫描手中实物 → 匹配官方谷库 → 点亮收藏**，以此保证公开展示的藏品照片具有**真实性与稀缺性**。

---

## 1. 产品定位与目标用户
- **定位**：谷子图鉴 + 私人收藏柜（谷柜）+ 换谷社区。
- **目标用户**：年轻二次元玩家（收藏、炫藏、换物）；**不是老年用户**。
- **核心差异化**：公开主页展示的藏品必须是"扫过实物、匹配上官方"的真货，保证稀缺性。

## 2. 平台与发布
- **先做安卓**（用 Capacitor 套壳现有 Web 站点），**后续上 Google Play + Apple App Store**。
- 复用现有 Web 后端（Next.js SSR/RSC + REST `/api/v1`），不另起前端。

## 3. 信息架构（底部 5 Tab）
```
首页    谷库    ( 扫描 )    换谷    我
                中间主按钮
```
- **排行** 归入「首页」；**谷柜** 收进「我」。
- Tab 用移动原生底部导航；扫描做成中间抬升的主按钮。

## 4. 核心功能需求

### 4.1 扫描点亮（最核心，最需打磨）
- 点「扫描」→ **直接全屏打开相机**，中间不要任何选择步骤。
- **只保留扫描，去掉"上传图片"**（已废弃功能）。
- 取景框 + **扫描指引光效**，要**好看且有用**。
- 拍一张 → **自动匹配官方谷库**（可复用开源图像特征匹配，如 CLIP）→ **自动入库**：
  - **匹配上官方谷子（高置信）→ 自动点亮 →「可在公开主页展示」**（真实、稀缺）。
  - **未匹配（盗版 / 二创 / 未收录）→ 也入库**，但**仅自己可见、不在公开主页展示**。
  - **全程无需审核、无需用户手动挑候选**。
- 目的重申：扫实物是为了保证主页展示的那张照片是真货、有稀缺性。

### 4.2 谷库（浏览 / 搜索）
- 全站 SKU 图鉴，按 **IP / 角色 / 系列 / 类型** 浏览与搜索。
- 公开浏览统一**原色**展示（不做明暗区分）。

### 4.3 谷柜（收藏，在「我」之下）
- 状态：拥有 / 想要 / 可换。
- **点亮**（扫描确认真实拥有）后由灰转彩。
- **未鉴定收藏**（扫了但没匹配官方）单列，仅自己可见。
- 可给藏品加**收藏边框**（玻璃镜面、按稀有度分档）。

### 4.4 换谷（以物易物市场）
- 公开 listings 市场 + 提案 / 履约流程。
- **无人民币 C2C 交易**（纯以物易物）。

### 4.5 首页（发现 Hub）
- 一屏逛完：**轮播（含预留广告位）+ 换谷市场 + 热门作品 + 最近收录 + 排行**。
- **首屏必须去噪**：不要大标题 + 大段营销文案，进来**直接看到有用内容**（搜索 + 内容流）。此项 Web 端也同步改。

### 4.6 我 / 个人主页 / 私信（对标抖音体系）
- **「我」页**：一块**紧凑资料头**（头像 + 名字 + @handle + **一行统计**：谷柜 / 关注 / 粉丝 / 徽章，均可点跳转）；换谷 / 私信 / 通知收成小入口。**目标：大幅减少下滑**。
- **公开主页 `/users/[handle]`**：同款紧凑头 + **藏品作品墙**（点亮的官方谷子网格）+ 关注按钮。对标抖音作品墙。
- **私信**：会话列表（头像 + 最新一条 + 未读红点）→ 气泡聊天。功能要**更健全**，对标抖音私信。

## 5. 全局约束（贯穿所有页面，最重要）
1. **保持简约**——信息密度克制、去噪，是最基本的约束。
2. **正常字号与图标尺寸**——满足正常使用即可，**不要巨大字体/图标**（用户是年轻人，**不做老人大字版**）。
3. **不伤害现有功能**——UI 可彻底重构，但保留功能与数据。
4. **符合 App 使用习惯**——底部 Tab、扫一扫、下滑流、气泡聊天等移动原生范式。

## 6. 品牌与视觉基调
- **日系「纸张博物馆」气质**：象牙纸底 + 墨黑字 + **朱红**（御朱印式印章强调）+ **古铜金**（珍藏标记）+ 青黛 / 雾蓝辅助。整体**安静、档案感、克制，不花哨、不霓虹/玻璃/金属堆砌**。
- **亮 / 暗双主题**都要成立。
- **App 图标 / 品牌徽标**：金边红盘 + 象牙月牙 + 金色四芒星。
- 参考色值（可微调）：纸 `#f7f1e5`、面 `#fcf8ee`、墨 `#242424`、细线 `#e4dbc8`、朱红 `#c94b4b`、青黛 `#486581`、古铜金 `#a8894f`。

## 7. 技术现状（背景参考，设计不必受限于此）
- Next.js（SSR/RSC）+ Drizzle + Postgres/Supabase；Capacitor 安卓壳（WebView 加载站点）。
- 扫描匹配：CLIP（transformers.js）图像特征 + 余弦相似度，官方图库已全部嵌入。
- 页面主体偏渐进增强（部分不做客户端水合）——需要交互的组件优先用**纯 CSS / 原生 HTML**，或确保其客户端脚本可靠运行；相机需**安全上下文（HTTPS / localhost）**。

## 8. 希望 AI 重点完善的方向
1. **扫描界面**：取景框、扫描光效、"识别中/已点亮/未鉴定"三态结果反馈的视觉与动效。
2. **首页首屏**：信息层级与去噪后的版式。
3. **「我」/ 公开主页 / 私信**：抖音式的紧凑布局与交互细节。
4. **统一尺度规范**：字号、间距、图标大小的一套克制、正常大小的规范。
